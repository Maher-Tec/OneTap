# Contributing to OneTap

Thanks for considering a contribution. OneTap is a Flutter mood journal that stores journal data locally on the device.

## Set up the project

1. Install Flutter and a supported editor or IDE.
2. Fork the repository and clone your fork.
3. From the project root, run:

   ```bash
   flutter pub get
   flutter run
   ```

## Before submitting a change

- Check existing issues and pull requests, and keep each change focused.
- Format Dart code with `dart format .` and run `flutter analyze`.
- Run relevant tests with `flutter test` when your change affects tested behavior.
- For UI changes, include screenshots and a short description of how to see the change.
- Never include real mood entries, notes, credentials, or other private information in commits, issues, screenshots, or pull requests.

## Pull requests

Describe what changed, why it is useful, and how you verified it. Link related issues when applicable. For substantial behavior changes, open an issue first so the approach can be discussed.
