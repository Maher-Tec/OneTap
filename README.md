# OneTap - Mindful Mood Journal 🌿

OneTap is a premium, privacy-focused mood tracking application designed to help you build emotional awareness through a simple, beautiful interface. With cinematic visuals, detailed insights, and a seamless user experience, OneTap makes daily journaling a moment of calm in your day.

## ✨ Features

- **Cinematic Experience**: Immersive video intro and beautiful, animated gradient backgrounds.
- **Effortless Logging**: Log your mood in seconds with a single tap.
- **Deep Insights**:
  - **Mood Distribution**: Visual pie charts showing your emotional balance.
  - **Weekly Summary**: Track your streak and weekly progress.
  - **Mood Trend**: Interactive line charts visualizing your emotional journey over time.
  - **Best Days**: Discover which days of the week you feel happiest.
- **Privacy First**: All data is stored locally on your device using Hive. No cloud, no tracking.
- **Premium Design**: Glassmorphism UI, haptic feedback, and smooth animations.

## 🛠 Tech Stack

- **Flutter**: Cross-platform UI toolkit.
- **Riverpod**: Robust state management.
- **Hive**: Fast, secure local key-value database.
- **FL Chart**: Powerful library for rendering graphs and charts.
- **Video Player**: For the cinematic intro experience.

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Maher-Tec/OneTap.git
    ```
2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```
3.  **Run the app:**
    ```bash
    flutter run
    ```
